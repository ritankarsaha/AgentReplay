# Security policy

Please report suspected vulnerabilities privately to **ritankar.saha786@gmail.com**
rather than opening a public issue. Include steps to reproduce; we aim to
acknowledge within 3 business days.

Notes for users: API keys are stored only as SHA-256 hashes and shown once;
traces may contain sensitive data, so use the SDK's `redact=` hook before
recording production traffic; projects are isolated per account.
